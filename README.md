# LMI PRO

**LUCKYMANU Market Intelligence PRO** — an institutional market-analysis system built in Pine Script.

## Current Stable Release

**v2.0.6 — Market Memory Foundation**

Phase 2 (Liquidity Engine) is complete and tested.

### Included capabilities

- Market-structure memory: HH, HL, LH, and LL
- Market-bias classification
- Equal-high and equal-low liquidity detection
- Buy-side and sell-side liquidity sweep tracking
- Event recording and an on-chart Market Memory dashboard
