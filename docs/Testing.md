# LMI PRO Testing

## Overview

Testing is a critical part of LMI PRO development.

Every version must be tested before being considered stable.

The goal is to ensure:

- Accuracy
- Stability
- Performance
- Reliability


# Testing Markets

LMI PRO will be tested across different market environments:

## Synthetic Markets

- Deriv Volatility 75 Index
- Other Deriv Synthetic Indices


## Traditional Markets

- Forex
- Gold
- Crypto
- Stocks
- Indices


# Testing Timeframes

## Higher Timeframes

Used for market direction:

- 4H
- 1H


## Execution Timeframes

Used for setup analysis:

- 15M
- 5M


# Testing Process

## Step 1 — Visual Testing

Check:

- Clean chart display
- Correct structure marking
- No excessive signals


## Step 2 — Logic Testing

Verify:

- Swing detection
- BOS detection
- CHOCH detection
- Liquidity identification
- Confirmation logic


## Step 3 — Performance Testing

Measure:

- Script speed
- Chart loading
- Resource usage


# Version Approval

A version can only be released after:

✓ Features work correctly  
✓ No major bugs exist  
✓ Testing is completed  
✓ Documentation is updated


# Development Principle

Test first.

Improve second.

Release last.
